Quick Answer

Before you release a glazing package, reconcile three sources line by line: the window/door schedule, the elevations, and the Division 08 specification. Log every conflict in size, glass type, finish, operation, or performance. Do not fabricate from the loudest document. Cloud the discrepancy and get a written direction.

Why three documents disagree

Schedules carry marks, sizes, and types. Elevations show configuration and sometimes different dimensions. Specifications set performance, glass makeups, finishes, and product-approval language. When they disagree, the fabricator will guess unless you force a written direction.

Reconciliation checklist

  • Every schedule mark appears on an elevation (and vice versa)
  • Width / height / rough opening notes match within allowed tolerance language
  • Operation type (fixed, projected, sliding, door) matches elevation
  • Glass type, makeup, and safety glazing locations match the glazing spec
  • Finish designation matches the finish schedule / Division 08 finish section
  • Design pressure / product approval language aligns with the specified system family
  • Hardware set numbers on doors match the hardware schedule
  • Thermal targets (U / SHGC) cite whole-product basis if the energy code path requires it

Release gate

Do not release fabrication while size, glass type, finish, or performance conflicts remain open. An “Approved as Noted” stamp that changes glass type is still an open gate until the note is incorporated and acknowledged. See the submittal process companion on Approved as Noted comment closure.

How to ask for a reconciled package

Send schedules, elevations, and the Division 08 sections that govern glass, finish, and performance. Attach a filled or blank conflict log. State material-only or furnish-and-install. ACG: (772) 486-7711. FL CGC #1531993.

Frequently Asked Questions

What three documents should be reconciled before ordering glazing?

The window/door schedule, the elevations, and the Division 08 specification sections that govern glass, finish, operation, and performance.

What if the schedule and elevation disagree on size?

Log the conflict and obtain written architect direction before fabrication. Do not average dimensions or invent a tolerance.

Is the specification always the controlling document?

Contract documents define precedence. Do not assume a universal hierarchy; follow the project conditions and written RFIs.

What should a GC attach to a glazing bid request?

Schedules, elevations, governing Division 08 sections, and a conflict log for any known mismatches.
