Quick Answer

Delegated glazing engineering only works when each party knows what they must provide. The architect sets design intent and criteria. The structural engineer of record defines building interface loads and acceptance rules when required. The glazing contractor (with its specialty engineer) provides system calculations and shop drawings within those limits. Write the handoffs before buyout. This is a process template, not a contract form.

What delegated design means here

On many Florida commercial jobs, the architect specifies performance and appearance. A specialty engineer retained through the glazing contractor then sizes members, anchors, and glass within the approved system and the stated criteria. That handoff fails when criteria, loads, or acceptance rules arrive after fabrication is already quoted as if they were known.

Required inputs before engineering starts

  • Stamped architectural elevations and schedules
  • Governing Division 08 performance sections
  • Wind / design criteria narrative used by the project
  • Structural interface information for anchors and deflections
  • Product-approval path expected (NOA / FL PA / other)

Typical glazier deliverables

Shop drawings, product data, calculations sealed by the specialty engineer when required, samples, and product-approval documentation for the exact configuration proposed. Contents still follow the project submittal schedule.

How to ask for a delegated package

Send drawings, specs, and a one-page note naming who provides structural interface data. State material-only or furnish-and-install. ACG: (772) 486-7711. FL CGC #1531993.

Frequently Asked Questions

Who provides design criteria for delegated glazing engineering?

Typically the architect (and structural engineer of record for building interface loads). The glazing specialty engineer designs the glazing system within those stated criteria.

Is this the same as a shop-drawing contents list?

No. This page assigns who provides inputs and who authors delegated-design deliverables. Package sheet lists live on the shop-drawings page.

Can fabrication start before delegated calcs are approved?

Not when the contract requires approved engineering before release. Treat open structural comments as a fabrication hold.

What should a GC send to start delegated engineering?

Elevations, schedules, Division 08 performance specs, and written structural interface data or a named SEOR contact.
