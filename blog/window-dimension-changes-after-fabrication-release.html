This page is a revision decision tree for dimension changes after fabrication release. It is not a general delays article. For late submittals, RFIs, and schedule risk before release, use how to avoid commercial glazing project delays.

Why post-release changes are different

Before fabrication release, a dimension change is usually a shop revision. After release, material may already be cut, glazed, finished, or on a truck. The options shrink to stop, scrap or rework, cancel, reorder, or absorb a field compromise.

This worksheet is a process template. It does not invent restocking fees, remake premiums, or calendar weeks.

Stop the affected release

Send a written hold that names the release ID and opening marks. Phone calls help, but the supplier needs a dated instruction. Unscoped “hold everything” language freezes unrelated packages and creates new delay.

Confirm whether glass is already laminated or units already glazed. Rework options change at each manufacturing stage.

Re-engineer vs cancel vs reorder

If the new dimension stays inside the tested configuration and approved makeup, revised shops and a new cut list may be enough. If the size leaves the approval envelope, treat it as a design change that needs engineering and AHJ review before anyone cuts glass again.

Cancellation and reorder are separate commercial acts. Ask the supplier to acknowledge both in writing: fate of the old material, and the new release ID for the replacement.

Field fillers, receptors, and shimming are not free substitutes for a wrong rough opening. Only use them when the design team accepts the detail in writing.

Documentation the GC must keep

Keep the original approved shop set, the revision cloud on the elevation or schedule, the hold email, the supplier acknowledgment, and the change-order path for cost ownership. Without that packet, remakes turn into finger-pointing.

Update the building/floor release register so receiving crews do not install the obsolete size by mistake.

How to send a dimension revision

Send revised elevations and the door and window schedule with a clear revision mark and date. List every affected opening. State material-only vs furnish-and-install. Ask for a written hold acknowledgment and a path: rework, cancel, or reorder.

Frequently Asked Questions

What should happen first when a window size changes after fabrication release?

Stop the affected release in writing with named marks and release IDs. Then decide whether the change fits the approved system, whether material can be reworked, and who owns remake and freight cost.

Is a post-release size change the same as a late RFI before shops are approved?

No. Pre-approval RFIs usually revise shops. Post-release changes may require holds, cancellation, remakes, and documented cost ownership. Use the delays guide for early risk; use this tree after release.

Can field fillers fix a wrong rough opening?

Only when the design team accepts the detail in writing and the system still meets the project requirements. Fillers are not a substitute for an unauthorized size change.

How should a GC request a revision path from the supplier?

Send revised drawings with revision marks, list affected openings, request a written hold acknowledgment, and ask for a clear path: rework, cancel, or reorder. Do not rely on verbal fee percentages.
