This page is a release-tracking guide for multi-building and multi-floor glazing packages. It is not a global project timeline. For phase durations and overall schedule framing, use the commercial glazing project timeline.

Why building and floor releases matter

On multi-building campuses and stacked towers, a single “ship everything” PO creates site chaos. Crates for Building B land while Building A still needs openings. Floors get mixed. The GC spends days sorting racks instead of installing.

Release control means each fabrication or shipping package is tagged to a building, a floor (or elevation zone), an opening-mark range, and a named receiving window. The goal is package segregation, not inventing calendar durations.

This register is a template. Fill it for your job. It is not a record of any ACG project and it does not invent lead-time weeks or ship dates.

How to segregate packages

Start from the door and window schedule, not from a lump quantity. Group marks by the earliest floor that can receive them, then by building. Entrances and lobby storefront often release ahead of typical floors because they control temporary enclosure.

Require the supplier to label crates and packing lists with Building / Floor / Mark range. A packing list that only says “Lot 1” is not release control.

Keep hardware and glass for the same marks in the same release when possible. Split hardware creates orphaned leaves on site.

Gates before fabrication release

Do not release a floor package until shops for that mark range are approved or the buyer issues a written release-at-risk. Verbal dimensions are not a release. See also shop approval is not a ship date.

Confirm finish, glass makeup, and hardware sets are frozen for that release ID. Mid-release color changes contaminate the whole floor package.

Receiving window discipline

Name a target receive window on the register. That window is a project coordination date, not a guaranteed manufacturer lead time. Align it with dry storage, elevator or crane access, and the install crew’s floor sequence.

If the floor is not ready, hold the release acknowledgment rather than accepting early freight into an unprotected laydown. Early crates still create damage and sorting cost.

How to ask for floor-released packages

Send elevations and the door and window schedule. Add one sentence: release by building and floor per attached register. State material-only vs furnish-and-install. Name the first building and floor that must ship.

Frequently Asked Questions

What is a glazing release by building and floor?

It is a fabrication or shipping package limited to a named building, floor or zone, and opening-mark range. Each package has its own shop status and receiving window so crates do not mix across floors.

How is this different from a project timeline article?

A timeline describes global phases. A release register controls package segregation and acknowledgment status. Use both: timeline for sequence, register for what ships when.

Should every floor get its own release?

Not always. Group by the earliest floor that can receive material and by shared finish or hardware sets. Entrances often release ahead of typical floors. Match the install sequence, not an arbitrary floor count.

How should a GC request floor-released packages?

Send elevations, the door and window schedule, and a one-line note: release by building and floor. Attach the register template and name the first package that must ship.
