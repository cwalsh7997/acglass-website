HVHZ guide

Florida's High Velocity Hurricane Zone is Miami-Dade and Broward. Exterior glazing there needs a current Miami-Dade NOA. The longer code path is on the HVHZ requirements page and the complete guide.

Send plans

Documented scopes get a proposal or budget direction in 48 hours. Lead times below are copied from the live system pages. They are not a new promise.

  • Storefront: 6-10 weeks material lead time. Installation 2-4 weeks for a typical 5,000-8,000 SF assembly.
  • Curtain wall: unitized 16-22 weeks from approved shop drawings; stick-built 10-14 weeks. Performance mock-ups add 8-10 weeks if specified.
  • Impact: standard impact storefront 6-10 weeks from approved shop drawings. Large-missile tested window wall 8-12 weeks. Custom impact sliders 10-14 weeks.
