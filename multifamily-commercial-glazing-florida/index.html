What we install

Eight scope categories. One general contractor.

01

Ground-floor amenity storefront

Aluminum systems with thermal break. Kawneer Trifab VG 451, YKK AP YES 45 IG, Tubelite T14000 — direct manufacturer relationships.

02

Building exterior punched windows

Impact-rated assemblies where the AHJ requires. ESWindows architectural series. Florida Building Code 1626 compliant in HVHZ markets.

03

Balcony glass railings

Laminated SGP with stainless structural patch fittings. Engineered for code-required guard loads.

04

Folding glass walls at amenity decks

Euro-Wall and NanaWall — verified installer. Indoor-outdoor amenity, pool deck, and event space transitions.

05

All-glass entrance doors

Structural patch fittings, automatic operators where ADA scope requires. Lobby and amenity entries.

06

Fire-rated corridor glazing

TGP, SAFTI FIRST, Vetrotech assemblies per Florida Fire Prevention Code corridor ratings.

07

Pool enclosures and rooftop rails

Laminated SGP with stainless cable rail or full panel. Coastal-rated stainless.

08

Tenant improvement re-glazing

Phased install on occupied multifamily assets. Weather protection between removal and reinstall.
