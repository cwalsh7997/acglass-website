Yes. ACG bids full commercial glazing installation with planned mobilization from our existing Florida offices. Send the job location, drawings and installation schedule so we can review the project and define the mobilization scope.

What should a GC send for a Jacksonville glazing bid?

Send the current drawings, glazing elevations, door and window schedules, specifications, addenda, job address and bid deadline. Include the target installation period and any delivery, access or staging restrictions.

Which commercial glazing systems can ACG review?

ACG reviews commercial storefront, curtainwall, window wall, impact windows and doors, and entrance systems. Identify the specified manufacturer and performance requirements so the bid addresses the actual opening package.

How are travel and return trips handled?

Mobilization, field measurements, deliveries, installation phases and return trips are reviewed against the project schedule and site conditions. Their scope and responsibilities should be stated in the written proposal and contract.
