## 1. Blue Book (The Blue Book Building & Construction Network) — 20 min

The Blue Book is still the most-used commercial-construction lookup for GC pre-bid invitations in Florida.

1. Go to [thebluebook.com](https://www.thebluebook.com).
2. Click **Add Your Company** (top-right) → **ProView Free Listing**.
3. Sign up with **connor@acglass.com**.
4. When asked for **Trade / Specialty Class**, select **Class 2230 — Glass and Glazing**.
5. When asked for **Service Region**, add BOTH:
   - **Florida — South** (region code "FL-South")
   - **Florida — North & Central** (region code "FL-N&C")
6. Paste the canonical NAP and short description above.
7. Add Connor as the primary contact.
8. Skip the upgrade-to-paid screen.
9. Submit. You'll get an email verification link — click it.

**Acceptance:** Blue Book ProView page exists at `https://www.thebluebook.com/iproview/<id>/american-commercial-glass/` (URL slug auto-generates).

## 2. Downtobid — 15 min

Downtobid is the newer GC-bid platform we hear referenced more often in 2026.

1. Go to [downtobid.com](https://downtobid.com).
2. Click **Claim your profile** or **Sign up as a subcontractor**.
3. Search for "American Commercial Glass" in their database first — they may have auto-imported a stub profile from public data. If a stub exists: **Claim** it. If not: create new.
4. Verify with **connor@acglass.com**.
5. Once in: **Profile** → rewrite the company description with the canonical short description above. Replace whatever placeholder copy they have.
6. Add the canonical NAP (HQ + 3 additional offices).
7. Trade selection: **Glass and Glazing** + **Storefront** + **Curtainwall** + **Impact Windows** if their taxonomy allows multiple.
8. Service area: All of Florida (statewide) + Middle Tennessee (Q3 2026).

**Acceptance:** Downtobid profile is yours, description is the canonical short version verbatim, and the company URL is in your control.
