Permit and code context in Palm Beach County

Palm Beach County issues permits through Planning, Zoning & Building Department. Municipalities (WPB, Boca, Delray, Jupiter) issue their own permits for projects within municipal boundaries.

Florida Building Code 8th Edition (2023) governs all glazing in Palm Beach County. Wind load is calculated per ASCE 7-22. Impact-rated assemblies (or approved shutters) are required for all openings exposed to design wind pressure.
